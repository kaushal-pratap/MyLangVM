# MyLangVM
This is stack-based bytecode virtual machine which I wrote in C. I will keep making it more advanced and more polished. This is my learning project.You can edit the instructions in Main.c like PSH, 5, ADD, MUL etc. in main.c to see how things changes. 

Run "make" command in terminal to build it and then ./mylangvm or ./mylangvm.exe for windows to run the program
